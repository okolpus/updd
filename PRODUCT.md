# Семантический атлас

Веб-приложение по ТЗ из Upd_otchet_3.docx для русскоязычных читателей и студентов. Основная задача — загрузить текст, увидеть граф сущностей и проверить предложенные связи по цитатам. Реальные аккаунты и библиотека, TXT/PDF/EPUB, заметки, аналитика, вопросы, PDF/PNG. FastAPI, React, PostgreSQL в Docker; SQLite для простого локального запуска.

Решения исполнителя: локальный анализ без платных ключей, честно обозначенные эвристики и извлечение цитат вместо генерации недоказанных ответов. Первое знакомство через отдельный демоаккаунт с оригинальным учебным рассказом. Точные родственные связи, мотивы и причины не считаются установленными фактами. Производительность на 500000 слов требует отдельного замера, не обещается без теста.

Главный экран — рабочий стол для изучения графа с библиотекой слева, графом в центре, источниками справа. По прямому уточнению пользователя интерфейс строится на бесплатной библиотеке Ant Design (MIT). Нейтральная светлая рабочая раскладка, стандартные формы, таблицы, вкладки и диалоги; обычный гротеск без декоративной типографики, слоганов и иллюстраций. Синий акцент и различимые цвета типов сущностей служат навигации. Мобильная версия сохраняет все действия и сворачивает боковые панели.
