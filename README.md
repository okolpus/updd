# Семантический атлас

Программа для исследования художественных и учебных текстов по техническому заданию из отчёта. Загрузите книгу или вставьте текст: приложение построит интерактивный граф, покажет цитаты, распределение упоминаний и темы глав. Можно сохранять заметки и искать фрагменты по вопросам.

## Быстрый запуск

На macOS дважды нажмите `start.command` или откройте терминал в этой папке и выполните:

```bash
bash start.sh
```

Понадобится Python 3.12 или новее и интернет при первой установке Python-зависимостей. Рекомендуется Python 3.12, на котором выполнены проверки; Python 3.14.1 исключён самой библиотекой NetworkX. Готовый интерфейс включён в `frontend/dist`, поэтому Node.js для обычного запуска не требуется. При отсутствии готовой сборки установите Node.js 22 LTS с npm. Скрипт установит зависимости в локальную `.venv` и запустит сервер.

Откройте **http://127.0.0.1:8765**. Для остановки нажмите Ctrl+C в терминале сервера. Повторный запуск сохраняет библиотеку и аккаунты. Не удаляйте `backend/data`: там находится локальная SQLite-база и ключ подписи сессий.

На первом экране создайте аккаунт или нажмите **«Открыть пример исследования»**. Пример использует отдельный случайный демоаккаунт и оригинальный учебный рассказ. Пароль демоаккаунта не выдаётся; для постоянной библиотеки создайте собственный аккаунт. Пока cookie демосеанса действует, его библиотека доступна в том же браузере.

## Что можно делать

- Регистрироваться, входить и выходить; менять имя, фотографию и настройку приватности профиля. Интерфейс на русском языке.
- Загружать TXT в UTF-8 или Windows-1251, PDF с текстовым слоем и EPUB. Размер файла — до 12 МБ; текст — до 500 000 слов и 12 миллионов символов. Для сканов сначала нужен OCR.
- Хранить несколько произведений с названием, автором, годом и жанром; искать, сортировать, редактировать метаданные и удалять тексты.
- Исследовать граф: двигать узлы и карту, менять масштаб, фильтровать типы сущностей, искать узлы и открывать основания связей.
- Читать главы и блоки, смотреть цитаты, частоту упоминаний, ключевые слова и динамику событий.
- Добавлять заметки к произведению, сущности или выделенному фрагменту.
- Задавать вопросы и сохранять историю найденных фрагментов.
- Скачивать PDF-отчёт и PNG-граф.

## Как устроен анализ

Анализ выполняется на сервере локально, без внешних API и платных ключей. `pymorphy3` приводит слова к начальным формам. Имена, географические названия, частотные понятия и слова, обозначающие события, становятся кандидатами в сущности. Совместные упоминания и языковые маркеры дают предполагаемые связи. `NetworkX` хранит структуру графа, D3.js визуализирует её.

Каждую связь нужно проверять по цитатам: совпадение имён, неоднозначность русской морфологии и совместное упоминание могут давать ошибки. Система не подтверждает фактическое родство, причины или мотивы. Представление ограничено 70 сущностями и 220 связями; полный текст остаётся доступен в режиме чтения.

Вопросы обрабатываются **поиском подходящих цитат**, без генеративной модели. Для точного поиска указывайте имя, место или понятие. Интерпретация мотивов и сюжетных конфликтов на уровне современной языковой модели в эту версию не включена. spaCy, transformers и LangChain из предложенного в отчёте стека не подключены: вместо них используется работающий автономный анализ. Это существенное отличие от нейросетевой части ТЗ.

Приватность профиля сохраняется как настройка. Публичная публикация библиотек и совместный доступ не реализованы: документы всегда доступны только владельцу аккаунта.

## Docker с PostgreSQL

Установите и запустите Docker Desktop. Создайте `.env` из примера и задайте независимые случайные значения:

```bash
cp .env.example .env
python3 -c 'import secrets; print(secrets.token_hex(32))'
```

Результат команды вставьте в `SECRET_KEY`. Повторите команду для `POSTGRES_PASSWORD`. В примере используйте пароль из шестнадцатеричных символов, чтобы не требовалось URL-кодирование строки подключения.

```bash
docker compose up --build -d
docker compose logs -f app
```

Откройте http://127.0.0.1:8765. Команда `docker compose down` останавливает контейнеры и сохраняет тома. `docker compose down -v` удаляет данные, поэтому не используйте её для обычной остановки.

Для публикации на сервере настройте HTTPS на обратном прокси и `COOKIE_SECURE=true`, передавайте корректный Host и Origin. Локально на HTTP оставьте `COOKIE_SECURE=false`. Не используйте значения секретов из примера. Перед публичной эксплуатацией нужны отдельные нагрузочные испытания, резервное копирование и проверка конфигурации инфраструктуры.

## Разработка

Сервер — FastAPI + SQLAlchemy; база — SQLite локально или PostgreSQL 16 в Docker. Схема создаётся при первом запуске. Интерфейс — React 18 + бесплатная UI-библиотека Ant Design 6 (MIT), Vite, D3.js и Lucide. Формы, таблицы, вкладки и диалоги используют настоящие компоненты Ant Design. API и пользовательские данные обслуживаются одним сервером.

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements.txt
.venv/bin/python -m pip install -r backend/requirements-dev.txt
cd frontend
npm ci
npm run build
cd ../backend
../.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8765
```

Для работы с Vite в отдельном терминале запустите `npm run dev` из `frontend`; `/api` проксируется на сервер. Интерактивная документация API — http://127.0.0.1:8765/docs, схема OpenAPI — `/openapi.json`, проверка сервиса — `/api/health`.

Сервер принимает переменные `DATABASE_URL`, `DATA_DIR`, `SECRET_KEY`, `COOKIE_SECURE`, `FRONTEND_ORIGIN`. При отсутствии `SECRET_KEY` локальный запуск создаёт и сохраняет ключ в каталоге данных. `.env` автоматически подхватывает Docker Compose; при ручном запуске задайте переменные окружения самостоятельно или используйте `uvicorn --env-file ../.env`.

```bash
cd backend
../.venv/bin/python -m pytest -q
```

Тесты используют отдельную временную SQLite-базу. Они проверяют регистрацию, сессии, отзыв cookie при выходе, доступ владельца, импорт файлов, граф с источниками, заметки, вопросы и экспорт. Сводка фактически выполненных проверок — в `VERIFICATION.md`.

Проверки защиты интерфейса от устаревших ответов выполняются командой `npm test` из `frontend`. Они моделируют задержанные ответы при смене аккаунта и произведения.

## Хранение и ограничения эксплуатации

Пароли хэшируются PBKDF2 с отдельной солью; JWT хранится в HttpOnly-cookie. Сессии записываются в базе и отзываются при выходе. Все операции с документами проверяют владельца. Файлы разбираются из памяти, EPUB не распаковывается на диск и ограничен по суммарному размеру. Изображения профиля проходят проверку формата и размеров.

Анализ синхронный: во время загрузки интерфейс показывает ожидание. Для массовой многопользовательской нагрузки нужны фоновые задачи и очередь. Гарантированные сроки восстановления 2/24 часа, отказоустойчивый кластер и миграции схемы не реализованы; это эксплуатационные требования, требующие отдельной инфраструктуры.

Шрифт DejaVu Sans включён для кириллического PDF/PNG. Лицензия находится в `backend/app/assets/DejaVu-LICENSE.txt`; лицензии компонентов интерфейса — в `THIRD_PARTY_NOTICES.txt`. Тексты пользователей не входят в поставку; деморассказ создан специально для программы.
